# 구조화 문항 품질 감사 (2026-10-13)

기준: 사용자가 제공한 `suneung-agent-database-1.skill`의 **로컬** `data/suneung_agent.sqlite`에서 SQL로 직접 계수. 여기의 수치는 원본 텍스트의 **정확성 검수**를 의미하지 않으며, 정답·정답률 검증이 따로 필요하다.

| 필드/검사 | 검출 행 수 | 전체 161,024행 대비 |
|---|---:|---:|
| 원문항 행 (`question_items`) | 161,024 | 100% |
| 지문/본문 길이 20글자 이상 | 103,788 | 약 64.5% |
| 해설 텍스트 길이 20글자 이상 | 134,771 | 약 83.7% |
| 정답 문자열 NOT NULL | 77,258 | 약 48.0% |
| 메가스터디 표본 정답률 연결 | 37,819 | 약 23.5% |
| 시험 메타데이터 수 | 7,200 | — |

**이 값은 필드 존재/길이 기준으로만 계산**했다. PDF 다단 조판으로 인한 문항 섞임, 수식/표 OCR 실패, 지문 불완전, 번호 불일치, 사설 통계 표본 편향이 해소되었다고 주장하지 않는다. 자료별 권리 확인 없이 캡처를 공개하지 않는다.

로컬 최신 DB에 다시 계산하려면:

```bash
python scripts/report_question_coverage.py --db workspace/suneung_agent.sqlite
```

## 문항 이미지 수집 검수 단계

1. 원본의 제공처와 실제 권리자 확인, 파일 URL·SHA-256 기록.
2. 문항/해설 PDF 페이지와 정규화된 bounding box를 `references/private_clip_manifest.example.csv` 형식으로 **각 문항별 검수**.
3. 권한 있는 로컬 파일에서 `batch_clip_manifest.py --apply --rights-confirmed` 수행.
4. 생성 이미지의 글자·도식·선지 누락 및 해설 번호 오연결을 사람이 확인하고 `image_assets.review_status='approved'`로 표시.
5. `link_clips_to_items.py --apply`로 원문 `paper_no`와 번호가 확정되는 이미지에만 `question_items.item_id` 연결. 애매하면 미연결 상태 유지.
6. 보유 증빙이 허용한 이미지에 한하여 별도로 공개 여부 결정.

검수 전 자동 일괄 공개 금지. 2단 편집 문제에서 임의 번호 정규식으로 잘못 자르면 문항-해설이 뒤바뀌는 심각한 데이터 오염이 생긴다.
