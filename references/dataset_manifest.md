# 데이터 매니페스트: 권리 분리 및 원본 품질 현황

소스의 시험문항 저작권자와 웹사이트 제공자를 혼동하면 안 됩니다.

| 원본 아카이브 구성 | 레코드 | 데이터 원천 / 권리 | 공개 여부 |
|---|---:|---|---|
| EBSi 기출 목록 / 파일 링크 | 7,200 건 | EBSi 수집, 개별 평가원 기출은 KICE 저작권 | 시험명·연도·링크 등 사실 메타데이터만 재구성 |
| KICE 공식 보도·수험자료 목록 | 123 건 | KICE 또는 자료별 원권리자 | 사실 메타데이터만 재구성 |
| `question_items` | 161,024 행 | EBSi 호스팅 원문 문제·해설 기반 | **비배포**: 문항 간 OCR/텍스트 혼합 사례 확인 |
| 메가스터디 문항별 정답률 | 77,650 행 | 메가스터디 채점 서비스 이용자 표본 | **비배포**, 별도 수집기/저장소 개념 |
| 메가스터디 등급컷 | 22,716 행 | 메가스터디 서비스 가공 통계 | **비배포**, KICE 통계로 오기 금지 |

**주의:** EBSi 기출 페이지는 EBSi가 *배포/호스팅한 위치*일 뿐, 평가원 저작권을 소멸시키지 않습니다. 교육 목적 및 비상업 고지는 타인 저작물의 복제·배포 허가가 아닙니다.

`research_catalog.sqlite`는 원본 제공 파일에서 추출한 사실 메타데이터/링크 및 독립적으로 정리한 교육 정책을 포함합니다. PDF 본문, 문항 지문, 정답지 원문, 문항 이미지, 계정 인증 정보는 포함하지 않습니다. 다단 편집 추출 문제 때문에 기존 문항 텍스트의 신뢰성은 원본 PDF 교차검증 전 **미검증** 상태입니다.

원본 파일·본문을 가지고 있는 개인은 본인이 취득한 정당한 이용허락 범위 안에서 로컬 `workspace/`로만 추가할 수 있습니다. 이미지 클립은 `scripts/clip_question.py`를 이용해 로컬에 생성하며 Git 저장소에 이미지 업로드하지 마세요.
